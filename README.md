# SuperOneliners
A collection of minima, one-liner implementations of algorithms solving some of basic mathematical problems.
Main goal for them is: Impementation must be a one-liner (and of course it must be working ;))



Languages:

- C#
- PHP
- Perl
- Python
- JavaScript
- SQL (XD)



Implemented algorithms:

- Calculating n-th power of number
- Calculating digital root of number
- Converting number decimal to binary
- Converting number binary to decimal
- Converting number decimal to hexadecimal
- Converting number hexadecimal to decimal
- Determining whether the number is prime
- Listing all primes up to the given number
